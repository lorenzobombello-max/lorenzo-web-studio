# Lorenzo Web Solutions

Lorenzo Web Solutions is a static website studio project focused on high-quality business websites and sector-specific demo experiences.

## What this repository contains
- Public website source (HTML, CSS, JavaScript)
- Demo pages and supporting assets
- GitHub Pages deployment workflow
- Supabase integration code for quote request flows

## Technology overview
- Frontend: static HTML/CSS/JS
- Backend integrations: Supabase Edge Functions
- Hosting: GitHub Pages

## Local development
Serve the repository root with any static server and open `index.html`.

## Deployment
Deployment is handled through GitHub Actions to GitHub Pages.

## Internal documentation policy
Internal project governance, decisions, and operational memory are intentionally kept outside this public repository in private project documentation.
