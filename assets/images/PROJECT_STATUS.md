## Standaard Workflow

Elke branche doorloopt verplicht deze volgorde:

1. Image Library
2. Manifest
3. Beeldplanning
4. Goedkeuring
5. Beelden verzamelen / genereren
6. Image Quality Review
7. HTML
8. CSS
9. JavaScript
10. Responsive controle
11. SEO controle
12. Accessibility controle
13. Homepage-integratie
14. Eindaudit
15. Definitieve oplevering

Geen stap mag worden overgeslagen.

## Projectregels

- AI_PROJECT_GUIDE.md is het hoogste beleidsdocument.
- Elke branche moet dezelfde kwaliteitsstandaard volgen.
- Geen branche mag worden geïmplementeerd zonder goedgekeurde beeldplanning.
- Geen demo mag op de homepage verschijnen zonder geslaagde audit.
- Alle wijzigingen moeten achterwaarts compatibel blijven.
- Manifesten zijn verplicht voor alle branches.
- PROJECT_STATUS.md wordt bijgewerkt na elke afgeronde projectfase.
