\## AI Guidelines



\- Use only images from this folder.

\- Use images only from this category unless explicitly instructed otherwise.

\- Prefer unique images per page.

\- Avoid using the same image twice on one page.

\- Reuse images only with different crops if necessary.

\- Keep image quality consistent.

\- Do not rename or move existing images without updating references.

\- Never use images from another business category.
