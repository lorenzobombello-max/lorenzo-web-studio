## 5. CSS-architectuur

- `assets/css/style.css` (1208 regels) is de enige globale stylesheet, geladen op elke pagina. Geen CSS-preprocessor, geen build stap, puur CSS3.
- Designtokens via custom properties in `:root` (o.a. `--color-primary`, `--color-accent`, `--space-section`, `--radius-*`, `--shadow-*`, `--container: 1140px`) met een volledige override-set in `[data-theme="dark"]` voor het licht/donker-thema.
- Responsive breakpoints (via `@media (max-width: …)`): `1100px`, `820px`, `640px`.
- `prefers-reduced-motion` wordt expliciet gerespecteerd (aparte regelblokken voor `no-preference` en `reduce`).
- Component-klassen volgen een BEM-achtige naamgeving (`.btn--primary`, `.portfolio-card--demo-industrial`, `.theme-toggle__sun`), maar het bestand bevat geen structurerende sectiecommentaren (geen `/* ... */`-koppen tussen blokken).
- `assets/css/demos/` bevat 4 demo-specifieke stylesheets, elk geladen bovenop `style.css` op de betreffende demo-pagina:
  - `industrieel-elektriciteit.css` — 1123 regels
  - `restaurant.css` — 798 regels
  - `mediterranean-brasserie.css` — 274 regels
  - `personal-portfolio.css` — 319 regels

## 6. JavaScript-architectuur

- Vanilla ES6, geen framework, geen bundler, geen build stap. `package.json` bevestigt dat er geen frontend-dependencies zijn geïnstalleerd.
- `assets/js/main.js` (301 regels) — globaal sitegedrag, IIFE-patroon: thema-toggle met `localStorage`-persistentie, mobiel navigatiemenu, scroll-reveal via `IntersectionObserver`, actieve-navlink-tracking, formuliervalidatie en beveiligde submit (`fetch POST`) naar de Supabase Edge Function `submit-quote-request`.
- `assets/js/review-request.js` (172 regels) — token-gebaseerde goedkeurings-/afwijzingsflow voor `pages/review-request.html`, communiceert met de Edge Function `review-quote-request`.
- `assets/js/demos/` bestaat als map maar bevat geen bestanden: de 4 live demo's draaien uitsluitend op `main.js` + hun eigen CSS-bestand, er is nog geen demo-specifieke JavaScript.

## 11. Technische keuzes (rechtstreeks afgeleid uit de code)

- Geen frontend-framework: statische HTML5/CSS3/ES6, geen bundler/build-tool. `package.json` bevat uitsluitend de Supabase CLI als dev-dependency.
- Theming volledig via CSS custom properties + `data-theme`-attribuut, met voorkeur-detectie (`prefers-color-scheme`) en persistentie via `localStorage`.
- Progressive enhancement voor animaties (`IntersectionObserver`, met respect voor `prefers-reduced-motion`).
- Backend uitsluitend via Supabase Edge Functions (Deno/TypeScript): `submit-quote-request` en `review-quote-request`, met gedeelde helpers in `supabase/functions/_shared/` (`cors.ts`, `email-templates.ts`, `rate-limit.ts`, `security.ts`, `types.ts`, `validation.ts`).
- E-mail uitsluitend server-side via Resend; geen API-keys in frontendcode (bevestigd: geen sleutels aangetroffen in `index.html`, `main.js` of `review-request.js`).
- 2 SQL-migraties aanwezig in `supabase/migrations/`, volgens `README.md` nog niet uitgevoerd op een echte database.
- Lokaal vangnet via `backup/` (16 tijdstempel-snapshots), git-ignored, in lijn met PROJECTREGEL 001 (back-up vóór wijziging).
