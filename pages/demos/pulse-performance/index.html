FAQ

Heldere antwoorden voor een snelle start.

Hoe start een traject bij Pulse Performance?

Je start met een intake en baseline test. Op basis daarvan maken we je eerste 8-weekse progression block.

Is dit alleen voor ervaren sporters?

Nee. We coachen zowel beginners als gevorderden, zolang je bereid bent om structureel te werken.

Hoe vaak worden schema's aangepast?

Minstens wekelijks op basis van performance data, recovery signalen en je planning.

Kan ik combineren met een drukke job?

Ja. De meeste leden zijn professionals. We bouwen je plan rond je agenda, niet omgekeerd.
